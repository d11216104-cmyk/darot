# darot

## 五子棋 (Gomoku / Five in a Row)

這個專案包含兩個版本的五子棋遊戲：

### 1. 命令列版本 (`gomoku_cli.py`)

**功能：**
- 15×15 棋盤
- 雙人對戰模式
- 支援多種輸入格式：`8 8`、`8,8`、`8, 8`
- 自動檢測勝利條件（5 子連線）
- 平局檢測

**使用方法：**
```bash
python3 gomoku_cli.py
```

### 2. 純網頁版本 (`gomoku.html`)

**功能：**
- 無需服務器，直接在瀏覽器中運行
- 精美的 UI 設計
- 視覺化棋盤和棋子
- 當前玩家高亮顯示
- 勝利動畫效果
- 重新開始功能

**使用方法：**
直接用瀏覽器打開 `gomoku.html` 文件即可開始遊戲

**遊戲規則：**
- 兩位玩家輪流落子（黑子先手、白子後手）
- 先在橫向、縱向或斜向連成 5 子或以上的玩家獲勝
- 棋盤滿而無人獲勝則為平局
